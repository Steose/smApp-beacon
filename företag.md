### Viktigt när du söker

Sök inte bara efter annonser med ordet **“LIA”**. Många IT-företag tar emot studenter efter direktkontakt. Skicka därför en kort spontanansökan till exempelvis:

> **Ämne: LIA – .NET Cloud Developer / Azure – Göteborg**
>
> Hej,
> Jag studerar till .NET Cloud Developer och söker LIA i Göteborg.
>
> Jag arbetar bland annat med **C#, .NET/ASP.NET Core, Microsoft Azure, Docker, GitHub Actions och Infrastructure as Code/Bicep**.
>
> Jag söker en LIA-plats där jag kan arbeta praktiskt med cloud development, backend, DevOps och Azure tillsammans med erfarna utvecklare.
>
> Jag bifogar gärna CV och GitHub/portfolio och berättar mer om mina projekt.
>
> Med vänliga hälsningar,
> Stephen

Din profil är dessutom mycket nära den kompetens som Göteborgsföretag redan annonserar efter. Till exempel listar Knowit Azure, Docker, Kubernetes, GitHub Actions och IaC, medan Sigma uttryckligen listar C#, .NET Core, ASP.NET Core, Azure, Docker, GitHub Actions och CI/CD. 

Jag skulle därför rekommendera att du inte bara skriver **“Jag söker LIA”**, utan leder med något i stil med **“.NET Cloud Developer – Azure / DevOps / IaC”**. Det gör det mycket tydligare för en engineering manager vad du kan bidra med.
